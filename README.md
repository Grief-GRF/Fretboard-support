# Fretboard 支持中心

Fretboard 是一款面向吉他和弦乐器学习者的音乐练习工具，提供指板学习、节拍器、调音器、练耳与乐理知识功能。

本仓库用于托管 Fretboard 的公开支持页面与隐私政策。

## 获取帮助

如需技术支持、提交问题或提出功能建议，请发送邮件至 [1074948869@qq.com](mailto:1074948869@qq.com?subject=Fretboard%20技术支持)。

为帮助我们更快定位问题，请在邮件中尽可能提供：

- 设备型号与系统版本
- Fretboard 版本号
- 问题的复现步骤
- 相关截图或录屏（如方便）

## 隐私

Fretboard 不收集、出售或共享个人数据。调音器需要麦克风权限以在设备本地实时检测音高；音频不会被录制、保存或上传。

完整政策请见 [隐私政策](privacy.html)。
